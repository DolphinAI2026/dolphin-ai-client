# 企业资产管理系统（V2 更新版）

## 一、系统概述

本系统用于管理企业固定资产的全生命周期，包括资产采购入库、领用分配、日常维修、定期盘点、调拨转移、报废处置及资产借用归还等核心业务流程。新增资产借用管理和合同管理模块，增强资产看板和统计分析能力。

## 二、角色设计

| 角色 | 说明 |
|------|------|
| 资产管理员 | 管理所有资产信息，处理入库、调拨、报废等操作 |
| 部门负责人 | 审批本部门的资产领用、调拨和报废申请 |
| 普通员工 | 提交资产领用、维修、报废申请，查看个人资产 |
| 财务人员 | 查看资产台账、折旧数据，审批报废的财务核销 |
| 仓库管理员 | 管理资产入库出库、库存盘点 |
| 公司领导 | 【新增】查看全部数据和统计报表，审批大额资产采购 |

## 五、审批流程

### 5.1 资产领用审批
- 申请人提交 → 部门负责人审批 → 资产管理员确认出库 → 完成

### 5.2 资产维修审批
- 报修人提交 → 部门负责人审批 → 资产管理员安排维修 → 完成

### 5.3 资产调拨审批
- 申请人提交 → 调出部门负责人审批 → 调入部门负责人确认 → 资产管理员执行调拨 → 完成

### 5.4 资产报废审批
- 申请人提交 → 部门负责人审批 → 资产管理员审核 → 财务人员核销 → **公司领导审批（资产原值≥5万元时）** → 完成

### 5.5 资产借用审批 【新增】
- 借用人提交 → 部门负责人审批 → 资产管理员确认 → 完成

### 5.6 合同审批 【新增】
- 负责人提交 → 部门负责人审批 → 财务人员审核 → 公司领导审批（合同金额≥10万元时）→ 完成

## 六、权限设计

- 资产管理员：所有表单全部操作权限，数据范围为全部
- 部门负责人：查看本部门及下级数据，审批领用/维修/调拨/报废/借用
- 普通员工：查看和新增本人数据，可提交领用、维修、报废、借用申请
- 财务人员：查看全部资产台账和折旧记录，管理合同，审批报废核销
- 仓库管理员：管理入库单、盘点单，查看资产台账全部数据
- 公司领导：【新增】查看全部数据（只读），审批大额报废和合同

## 七、自开发需求 【新增章节】

以下功能无法通过标准配置实现，需要自开发：

### 7.1 资产看板页面（自开发菜单页面）
- 资产总数、总价值、各状态数量的统计卡片
- 按分类的资产分布饼图
- 按部门的资产分布柱状图
- 近12个月的折旧趋势折线图
- 即将到期维保资产预警列表

### 7.2 资产标签打印组件（自开发表单组件）
- 在资产台账表单中嵌入"打印标签"按钮
- 生成包含资产编号、名称、二维码的标签
- 支持批量打印

### 7.3 资产地图定位页面（自开发菜单页面）
- 在地图上展示各办公区域的资产分布
- 点击区域可查看该区域资产列表
- 支持按分类筛选
