# 桌面登录页优化设计

## 目标

让桌面端登录页能清晰表达当前远程服务，并提供可用、低干扰的登录服务切换入口。

## 已确认问题

- 登录卡片中的“更改登录服务”在网页桌面预览中调用的是空操作，点击后没有页面变化。
- 当前入口是横向文字按钮，会和服务摘要争抢空间，窄屏下尤其不协调。

## 设计

- 保留现有桌面端左右分栏结构和账号、密码、验证码真实认证逻辑。
- 登录卡片右上角使用设置/切换图标作为唯一服务切换入口，提供 `title` 和 `aria-label`。
- 标题下方使用紧凑服务摘要，展示平台、认证方式和可用工作台能力。
- 网页桌面预览点击图标后路由到 `/desktop-setup`；Tauri 正式包继续调用 `desktop_enter_login_setup`。
- 切换过程中锁定登录表单和入口图标；失败时恢复入口并显示错误提示。
- 视觉上降低装饰背景的对比度，提升登录卡片层级、留白和移动端适配。

## 非范围

- 不修改登录 API、验证码接口、租户选择和认证数据结构。
- 不重构桌面后端生命周期或服务发现协议。

## 验收

1. 网页桌面预览点击卡片右上角图标后进入初始化服务页。
2. Tauri 桌面端仍使用原生登录服务配置命令。
3. 登录页在桌面和窄屏视口中摘要不溢出、图标可识别、表单可正常提交。
