# Builder Code 嵌入式体验优化设计

**Spec ID**：`2026-07-16-builder-code-embedded-experience`
**日期**：2026-07-16
**状态**：已确认，进入实现
**协同仓库**：`apaas-builder-ai`、`agent-runtime`

## 1. 目标

Builder 中的 Code 页面应表现为一个完整、稳定的工作台，而不是两个独立页面的简单 iframe 拼接。用户在进入、切换会话、阅读长任务、查看任务状态、滚动到底部、添加附件和审查文件时，不应感知宿主与沙箱之间的边界。

本次只优化现有 Code 工作台体验，不扩展新的业务流程、数字员工能力或会话模型。

## 2. 工程边界

- `apaas-builder-ai` 负责外层路由、会话打开、iframe 生命周期、宿主遮罩、跨窗口消息校验和会话切换原子性。
- `agent-runtime` 负责 iframe 内部 Builder 对话、滚动定位、任务面板、消息与文件卡片、输入区和附件上传。
- `control-plane` 继续负责沙箱和会话运行入口，不承载本次界面状态。

## 3. 核心体验

### 3.1 进入与切换

- 首次进入显示明确的工作台加载状态。
- 切换会话时保留旧页面作为视觉占位，但旧页面立即不可交互。
- 新 iframe 的原生 `load` 只代表文档已加载，不能直接完成切换。
- 只有新 iframe 发出可信的 `builder.ready` 后，宿主才一次性切换 iframe、会话状态和交互权限。
- 新页面准备失败时，恢复旧页面交互并显示可重试错误，不能留下半切换状态。
- 宿主只接受来自当前 iframe、可信 origin 的消息。

### 3.2 跨窗口协议

宿主向内层发送：

- `shell.visibilityChanged`：当前 iframe 是否可见、是否允许交互。
- `shell.sessionActivationChanged`：当前 frame key 和激活状态。

内层向宿主发送：

- `builder.ready`：内层已完成首屏初始化，可接管展示。
- 现有运行状态事件继续保留。

协议消息必须带可判定的 frame 身份，避免旧 iframe 的迟到消息污染新会话。

### 3.3 滚动

- 用户位于底部时，新消息、流式输出、文件卡高度变化和附件区变化继续自动贴底。
- 用户主动离开底部后，不强制拉回；新内容累计为未读提示。
- 显示稳定的“回到底部”按钮，点击后清空未读并回到底部。
- iframe 隐藏期间不执行无意义的滚动动画；重新激活时根据原有 pin 状态恢复。
- 使用内容尺寸观察补偿异步高度变化，避免回复中卡片展开造成页面抖动。

### 3.4 任务、数字员工与 Trace

- 外部嵌入模式在桌面宽屏使用右侧停靠面板，宽度控制在 `360-400px`，不覆盖主对话。
- 面板内使用“任务 / 数字员工 / Trace”分区或标签，继续复用同一份运行状态。
- 较窄桌面窗口退化为带遮罩的抽屉，不与输入区叠加。
- 面板打开和关闭不能重挂载 ChatPane，不能丢失草稿、附件或滚动位置。

### 3.5 卡片层级

视觉优先级为：

1. 用户问题与 AI 正文。
2. 当前执行摘要和待确认事项。
3. 文件修改汇总。
4. 思考、工具和原始 Trace。

文件汇总默认显示前 3 个文件，其余折叠；文件名为主信息，路径为次信息，整行可打开文件，审查入口展示真实 diff。重复文件事件按真实路径聚合。

### 3.6 输入与附件

- 底部只保留一个动态高度 Dock，状态、附件、输入和操作按钮按内容自然增长。
- 移除外部嵌入模式中的固定 `82px/106px` 高度依赖，避免附件覆盖输入区。
- `+` 菜单提供明确的“上传文件”入口，同时保留粘贴和拖拽。
- 多文件并行上传；每个文件显示进度、失败原因、重试和移除。
- 会话切换和不可见状态下输入立即禁用，防止内容发往错误会话。

## 4. 视觉约束

- 延续现有 Dolphin Code 中性、工作型界面，不增加营销式大卡片或装饰背景。
- 主对话、文件卡、任务面板和输入 Dock 使用统一边框、间距和状态色。
- 减少等权重边框，思考与工具默认折叠并降低视觉权重。
- 所有图标按钮具有可访问名称和 tooltip。
- 中英文状态文案统一为中文；技术标识仅在 Trace 中保留。

## 5. 验收矩阵

桌面端至少验证：

- `1920x1080`
- `1600x1000`
- `1440x900`
- `1280x800`

每个关键宽度覆盖：

- 短会话 / 长会话。
- 位于底部 / 离开底部。
- 任务面板关闭 / 打开。
- 无附件 / 多附件上传 / 上传失败重试。
- 会话切换成功 / 新 iframe 加载失败。
- 输入上下文弹层打开。

## 6. 非目标

- 不修改数字员工编排和工作树规则。
- 不重做会话历史模型。
- 不引入文件锁、运行时锁或新的后端持久化状态。
- 不用 mock 替代真实 iframe、上传、文件打开和 diff 数据链路。
