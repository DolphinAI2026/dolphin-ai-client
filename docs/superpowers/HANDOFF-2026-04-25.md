## 关键技术决策回顾

1. **数据形态：X′ 纯结构化 SPEC + markdown 仅 derived 导出**
   不是双轨同步，不是 frontmatter 增强 markdown。SPEC 是 single source of truth，markdown 是 view。

2. **phase 拆分：P3 — gathering / drafting / generating / ready**
   跟现有 PhaseBar 5 段一一对应，UI 0 改动。允许回退。

3. **LLM 协议：T — Tool calling**
   不是末尾 JSON 块。omnigate 已支持（vibe_agent 验证）。22 个 atomic tool。

4. **first-turn enforcement**
   gathering 首轮 `add_*` / `set_goal` 被 dispatch_tool 拒绝，强制 LLM 先 `ask_clarifying_question` 至少 3 次。在 chat 流跑通了；bootstrap_from_doc 不强制（doc 是答案）。

5. **CodingPage 重设：Workspace-first**
   不是 split / command-first。删整个 hero（标题/glyph/eyebrow），composer 单行，工作区列表前置到首屏。
