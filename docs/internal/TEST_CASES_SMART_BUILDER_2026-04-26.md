# 智能搭建测试用例

**版本**: v1.0
**日期**: 2026-04-26
**范围**: 智能搭建 0-1 创建低代码应用、1-N 迭代已有应用
**入口**: `ChatPage` / `/chat` / `/work/:appId` 跳转后的智能搭建模式

## 1. 测试目标

验证智能搭建从自然语言或设计文档出发，能完成低代码应用的需求收集、SPEC 生成、配置预览、应用创建、平台发布和后续增量迭代。

核心结论按两条链路验收：

| 链路 | 验收重点 |
| --- | --- |
| 0-1 创建应用 | 从空会话创建应用，生成角色、字典、模型、表单、权限，并可在平台侧读回 |
| 1-N 迭代应用 | 基于已发布应用做增量更新，只变更目标资源，不误删或重建无关资源 |

## 2. 前置条件

| 项目 | 要求 |
| --- | --- |
| 服务 | 后端 `8000`、前端 `5173` 可访问 |
| 账号 | 已登录，已选择租户，具备创建和发布测试应用权限 |
| 平台连接 | aPaaS 环境连接正常，连接状态可在页面或接口读到 |
| 模型 | 智能搭建用途模型可用，禁用模型不出现在选择器中 |
| 测试命名 | 应用名统一带 `TC智能搭建_YYYYMMDD_HHMM`，避免和真实业务冲突 |
| 数据清理 | 测试应用仅用于验证，发布到测试租户，不绑定真实生产流程 |

## 3. 基准测试数据

### 3.1 0-1 应用需求

应用名称：`TC智能搭建_供应商准入与风险管理`

业务描述：

> 搭建一个供应商准入与风险管理系统。采购管理员维护供应商主档和证照资料；风控专员记录风险事件、整改计划和审核状态；供应商协同人员只能查看自己的整改事项。系统需要支持供应商状态、风险等级、审核状态字典，支持供应商主表、证照资料、风险事件、整改计划四类业务对象，并给不同角色配置权限。

期望资源：

| 类型 | 内容 |
| --- | --- |
| 角色 | 采购管理员、风控专员、供应商协同人员 |
| 字典 | 供应商状态、风险等级、审核状态、证照类型 |
| 模型 | 供应商、证照资料、风险事件、整改计划 |
| 表单 | 供应商档案、证照资料、风险事件、整改计划 |
| 权限 | 采购管理员全权限，风控专员可维护风险与整改，供应商协同人员只读供应商和维护自己整改 |

### 3.2 1-N 迭代需求

基于 0-1 应用继续迭代：

> 在已有供应商应用中增加年度复审功能。新增复审记录模型和表单，供应商主档增加风险评分字段，风险等级字典增加“黑名单”选项。风控专员可以新增和审核复审记录，采购管理员可以查看全部复审记录，供应商协同人员不能看到复审记录。

期望增量：

| 类型 | 变更 |
| --- | --- |
| 新增模型 | 复审记录 |
| 新增表单 | 供应商年度复审 |
| 新增字段 | 供应商.风险评分 |
| 更新字典 | 风险等级新增“黑名单” |
| 更新权限 | 新表单按角色配置，旧表单权限不被覆盖 |

## 4. 通过标准

| 编号 | 标准 |
| --- | --- |
| AC-01 | 生成的 SPEC 与预览内容一致，模型、表单、权限语义不混写 |
| AC-02 | 0-1 应用创建后能从应用列表进入，平台侧能查到应用、模型、表单和权限 |
| AC-03 | 1-N 更新展示差异预览，执行前能看到新增、修改、保持不变的资源 |
| AC-04 | 1-N 执行后，旧资源 ID 或编码保持稳定，非目标资源不被删除或重建 |
| AC-05 | 失败场景可见、可恢复，错误不会只停留在控制台 |
| AC-06 | 刷新页面或重开会话后，关键聊天、SPEC、预览和部署状态可恢复 |

| SB-010 | P0 | 增量差异预览 | 查看新增复审记录、风险评分、黑名单选项和权限变更 | 差异按角色、字典、模型、表单、权限分组；旧资源显示保持不变 | Diff 截图 |
| SB-011 | P0 | 执行增量更新 | 确认差异后执行更新；观察更新进度 | 只执行有差异的阶段；完成后返回成功结果；旧供应商、风险事件等表单仍可用 | 进度截图、结果 JSON |
| SB-012 | P0 | 增量读回验证 | 进入平台侧检查风险评分字段、黑名单选项、复审表单和权限 | 新资源存在；原供应商档案字段未丢失；原权限未被重置 | 平台截图、接口读回 |
| SB-013 | P1 | 文档上传 0-1 | 上传一份标准设计文档，包含 0-1 应用需求；触发解析 | 标准度高的文档可直接预填或生成结构化结果；低标准文档提示补充而非静默失败 | 上传结果、解析日志 |
| SB-014 | P1 | 文档上传 1-N | 对已有应用上传 V2 设计文档，新增复审功能 | 识别为基于当前应用的文档版本差异；展示 V1/V2 对比和变更计划 | 文档对比截图 |
| SB-015 | P1 | 编码冲突处理 | 使用容易重复的模型编码或字典编码创建测试资源 | 系统提示冲突资源；允许调整编码后重试；不会跳过失败阶段继续发布不完整应用 | 错误提示、重试结果 |
| SB-016 | P1 | 权限边界 | 用不同角色登录或模拟权限读回，检查表单能力 | 采购管理员、风控专员、供应商协同人员权限符合预期；无越权入口 | 权限截图 |
| SB-017 | P1 | 自开发边界识别 | 在需求中追加“做一个复杂图表风险看板页面” | 智能搭建应说明低代码配置覆盖范围，复杂看板建议进入睿鲸 Coding 或自开发任务，不强行塞入普通表单 | AI 回复、派发入口 |
| SB-018 | P1 | 断线与重试 | 构建或增量执行中刷新页面、断网后恢复、或接口临时失败后重试 | 已完成阶段不重复创建；当前阶段可重试；页面有可读错误说明 | 重试记录 |
| SB-019 | P2 | 空需求防御 | 输入“帮我搭个系统”但不提供业务对象 | AI 继续追问行业、对象、角色、流程，不生成低质量应用 | 聊天记录 |
| SB-020 | P2 | 非测试租户保护 | 在无平台连接或无权限账号下点击构建 | 构建按钮禁用或给出明确权限/连接错误，不产生部分资源 | 错误提示 |
