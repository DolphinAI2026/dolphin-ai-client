### 功能概述

| 页面 | 逻辑功能 | 逻辑概述 |
| --- | --- | --- |
| 配额申请 | 附件上传 | 上传线下签订完成的配额批准书 |
| 配额申请 | 状态变更 | 将配额批准书状态更新为生效中，提示：共同声明书、劳务合同、委托书是否均存在并且通过审批，如果不符合条件，提示 哪些文件未完成 |

| 配额申请 | 到期提醒 | 1、续约提醒在配额结束时间前9个月前提醒<br>2、劳工招聘提醒，距离有效期还有配额数量未使用，40天 |
| 配额申请 | 生成委托书 | 点击后基于配额申请创建委托书 |
| 配额申请 | 生成共同声明书 | 点击后基于配额申请创建共同声明书 |

| 委托书 | 生成账单 | 生成对账单（只有配额申请费） |
| 劳务合同 | 作废 | 将委托书作废，点击后可将状态改成失效 |
| 劳务合同 | 打印模板 | 根据不同行业类型，生成不同打印模板 |

#### 功能逻辑

- - 配额占用

功能说明：当劳工信息生成后自动分配配额明细编号

入参：

分配人员ID、分配人员姓名、有效时间开始、有效时间结束、批文编号、行业

处理逻辑：

1. 校验分配人员ID、分配人员姓名、批文编号，是否在【配额明细表】内存在【明细配额分配状态】为已分配、【是否生效】为生效的数据

如果存在调用失败提示，该人员已经分配，请勿重复分配

如果不存在执行2

1. 查询出配额序号最小一条且【明细配额分配状态】为未分配或部分分配的【配额明细】数据，更新【分配人员ID】、【分配人员】、【有效时间开始】、【有效时间结束】为入参来源值、【绑定时间】为当前，【明细配额分配状态】为已分配
2. 插入【配额明细记录】，按照页面字段规则生成
   - 取消配额占用

功能说明：调用后需要配额明细占用，仅支持在evisa办理前调用

入参：

分配人员ID、分配人员姓名

处理逻辑：

1. 校验人员ID是否在【配额明细表】内存在

如果不存在则提示：未查询到该用户有占用配额。

1. 更新配额明细清空【有效时间开始】、【有效时间结束】，【分配人员ID】、【分配人员】，更新人员台账清空【分配人员ID】、【分配人员】、【配额编号】取消分配
   - 配额替换占用

入参：

分配人员ID、分配人员姓名、配额明细ID

处理逻辑：

1. 校验配额明细ID是否存在，如果不存在提示：配额明细ID不存在，请确认；
2. 如果存在校验配额明细ID，可替换次数是否大于0，如果小于0提示当前配额明细ID已经无法替换，请确认；
3. 如果可替换次数大于0，根据配额明细ID查询配额明细，更新对应劳工配额明细为空；再根据分配人员ID将配额明细ID赋值至当前劳工信息，并插入配额明细记录，最后根据配额明细ID更新配额明细表，更新配额替换次数-1，已替换次数+1，绑定劳工更新为分配人员。
