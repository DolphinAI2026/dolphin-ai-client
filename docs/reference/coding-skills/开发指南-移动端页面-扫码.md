## 一、命名规范（铁律，不可违反）

假设你要开发的页面叫 `xxx`（如 `checkin-m`、`inventory-pc`），则：

| 需要命名的位置 | 值 | 示例 |
|---|---|---|
| package.json `name` | `form-page-xxx` | `form-page-checkin-m` |
| apaas.json `outputName` | `form-page-xxx` | `form-page-checkin-m` |
| apaas.json `router` 的 key/name/path | `apaas-custom-xxx` | `apaas-custom-checkin-m` |
| Vue.component 注册名 | `apaas-custom-xxx` | `apaas-custom-checkin-m` |
| .vue 文件名 | `apaas-custom-xxx.vue` | `apaas-custom-checkin-m.vue` |
| .vue 根元素 class | `apaas-custom-xxx` | `apaas-custom-checkin-m` |
| apaas.json `copyAssets` | `["public/form-page/form-page-xxx"]` | `["public/form-page/form-page-checkin-m"]` |

**强制前缀**：组件名必须以 `apaas-custom-` 开头，否则平台无法加载。

### 3.3 `src/index.js` — 入口文件

```js
import "./form-page-local/index.js"; // 引入国际化（不能删除这行）
import ApaasCustomPage from "./form-page/apaas-custom-{{PAGE_NAME}}.vue";

const install = function (Vue) {
  Vue.component("apaas-custom-{{PAGE_NAME}}", ApaasCustomPage);
};

const FormPage = {
  install: install,
};

export default FormPage;
```

**要点**：
- 第一行 `import "./form-page-local/index.js"` 不能删，平台运行时依赖它注册国际化词条。
- `Vue.component` 的名称必须和 `apaas.json` 的 `router` key 完全一致。
- 导出的对象必须有 `install` 方法（Vue 插件规范），平台通过 `Vue.use()` 加载。

### 3.4 `src/api/index.js` — 接口定义

```js
const api = {
  // 示例：一个 POST 接口
  MY_ACTION: {
    url: "/custom/xxx/your-endpoint",
    method: "POST",
    disableSuccessMsg: true,
  },
  // 示例：一个 GET 接口
  QUERY_SOMETHING: {
    url: "/custom/xxx/query-something",
    method: "GET",
    disableSuccessMsg: true,
  },
};

export default api;
```

**要点**：
- 每个接口定义为 `{ url, method, disableSuccessMsg }` 对象。
- `disableSuccessMsg: true` 阻止平台自动弹出成功提示（由业务自行控制 UI 反馈）。
- url 通常以 `/custom/` 开头（自定义后端接口）或 `/xdap-app/`（平台标准接口）。

### 3.5 `src/form-page/apaas-custom-{{PAGE_NAME}}.vue` — 业务页面组件

这是核心文件。下面给出**完整的骨架模板**和**接口调用范式**：

```vue
<template>
  <div class="apaas-custom-{{PAGE_NAME}}">
    <!-- 头部 -->
    <div class="header">
      <span class="header-title">{{PAGE_TITLE}}</span>
    </div>

    <!-- 业务内容区 -->
    <div class="section">

      <!-- 你的业务 UI -->
    </div>

    <!-- 操作按钮 -->
    <div class="btn-wrap">
      <button class="primary-btn" :disabled="loading" @click="handleSubmit">
        {{ loading ? '处理中...' : '提交' }}
      </button>
    </div>

    <!-- 结果展示 -->
    <div v-if="result" class="section result-section">
      <div class="section-title">执行结果</div>
      <div class="result-card" :class="result.success ? 'result-success' : 'result-fail'">
        <div v-if="result.success" class="result-rows">
          <!-- 成功时展示的字段 -->
          <div class="result-row" v-for="(val, key) in result.data" :key="key">
            <span class="result-label">{{ key }}</span>
            <span class="result-value">{{ val }}</span>
          </div>
        </div>
        <div v-else class="result-fail-msg">{{ result.msg }}</div>
      </div>
    </div>

    <!-- Toast 提示 -->
    <div v-if="toastMsg" class="toast">{{ toastMsg }}</div>
  </div>
</template>

<script>
import api from "../api/index.js";

export default {
  data() {
    return {
      loading: false,
      result: null,
      toastMsg: "",
      // ... 你的业务数据
    };
  },
  methods: {
    /**
     * ★★★ 核心：接口调用范式 ★★★
     *
     * 得帆平台的 this.$request 不是 axios，返回的不是 Promise。
     * 它返回的是一个链式对象，只能用 .asyncThen() 和 .asyncErrorCatch()。
     *
     * 如果你需要用 async/await 或 .then()/.catch()，
     * 必须手动包一层 new Promise。
     */

    // ---------- 方式一：直接链式调用（简单场景推荐） ----------
    callApiDirect(params) {
      this.loading = true;
      this.$request({
        url: api.MY_ACTION.url,
        method: api.MY_ACTION.method,
        params: params,
      })
        .asyncThen(
          (res) => {
            // 成功回调（res.code === 0 或 res.code === 'ok'）
            this.loading = false;
            if (res.code === 0) {
              this.result = { success: true, data: res.data };
            } else {
              this.result = { success: false, msg: res.msg || "操作失败" };
            }
          },
          (err) => {
            // 业务失败回调
            this.loading = false;
            this.result = { success: false, msg: err.msg || "操作失败" };
          }
        )
        .asyncErrorCatch((err) => {
          // 网络异常回调
          this.loading = false;
          this.result = { success: false, msg: "网络异常，请重试" };
          console.error(err);
        });
    },

    // ---------- 方式二：包装成 Promise（需要 await 或链式处理时用） ----------
    callApiWithPromise(params) {
      this.loading = true;
      new Promise((resolve, reject) => {
        this.$request({
          url: api.MY_ACTION.url,
          method: api.MY_ACTION.method,
          params: params,
        })
          .asyncThen(
            (json) => resolve(json),
            (err) => reject(err)
          )
          .asyncErrorCatch((err) => reject(err));
      })
        .then((res) => {
          if (res.code === 0) {
            this.result = { success: true, data: res.data };
          } else {
            this.result = { success: false, msg: res.msg || "操作失败" };
          }
        })
        .catch((err) => {
          this.result = {
            success: false,
            msg: (err && err.msg) || "网络异常，请重试",
          };
        })
        .finally(() => {
          this.loading = false;
        });
    },

    handleSubmit() {
      // 调用示例
      this.result = null;
      this.callApiWithPromise({ key: "value" });
    },

    // Toast 提示（无依赖的轻量实现）
    showToast(msg) {
      this.toastMsg = msg;
      setTimeout(() => {
        this.toastMsg = "";
      }, 2500);
    },
  },
};
</script>
```

### 3.8 `src/mixin/custom-permissions.mixin.js`（可选引入）

```js
const apis = {
  QUERY_CUSTOM_PAGE_PERMISSIONS: {
    url: '/xdap-app/appSelfDevPermission/listPermAccesses/byMenuIdAndUserId',
    method: 'get',
    disableSuccessMsg: true
  }
}
export default {
  data() {
    return {
      customPagePermissions: []
    }
  },
  computed: {
    permissionStatus() {
      return function(permCode) {
        if (!permCode) return false
        const permArr = this.customPagePermissions &&
          this.customPagePermissions.filter(item => permCode === item.permissionCode)
        return permArr && permArr.length > 0
      }
    }
  },
  created() {
    this.queryUserCustomPagePermissions()
  },
  methods: {
    queryUserCustomPagePermissions() {
      const request = {
        ...apis.QUERY_CUSTOM_PAGE_PERMISSIONS,
        params: { menuId: this.$route.query.currentMenu }
      }
      this.$request(request).asyncThen(resp => {
        if (resp.code === 'ok') {
          this.customPagePermissions = resp.data && resp.data.map((item) => {
            if (item.selfDevPermission) return item.selfDevPermission
          })
        }
      }, (err) => {
        console.error(err)
      }).asyncErrorCatch((err) => {
        console.error(err)
      })
    }
  }
}
```

```js
  // 然后在模板中用 v-if="permissionStatus('PERM_CODE')" 控制按钮权限
}
```

### 4.3 `preview/mock-request.js` — Mock $request 链式调用

```js
/**
 * Mock 得帆平台 $request 方法
 *
 * ★ 关键：必须返回 { asyncThen(), asyncErrorCatch() } 链式对象
 * ★ 绝对不能返回 Promise！组件代码里写的是 .asyncThen()，不是 .then()
 */

function createMockResponse(config) {
  const url = config.url || ''
  const params = config.params || {}

  // ====== 在这里按 url 匹配，返回模拟数据 ======

  // 示例：匹配你的业务接口
  if (url.indexOf('/custom/xxx/your-endpoint') > -1) {
    return {
      code: 0,
      data: {
        id: 'MOCK-001',
        status: '成功',
        time: new Date().toLocaleString('zh-CN'),
        // ... 根据业务返回的字段
      },
      msg: '操作成功',
    }
  }

  // 默认响应
  return { code: 0, data: {}, msg: 'ok' }
}

function createChainable(config) {
  const response = createMockResponse(config)

  const chainable = {
    asyncThen(onSuccess, onError) {
      setTimeout(() => {
        try {
          if (response.code === 0) {
            onSuccess && onSuccess(response)
          } else {
            onError && onError(response)
          }
        } catch (e) {
          console.error('[mock-request] asyncThen error:', e)
        }
      }, 300) // 模拟 300ms 网络延迟
      return chainable // ★ 必须返回自身，支持链式
    },
    asyncErrorCatch(onError) {
      // mock 环境一般不触发网络错误
      // 如需测试异常场景，可在这里 setTimeout 调用 onError
      return chainable // ★ 必须返回自身
    },
  }

  return chainable
}

export default function mockRequest(config) {
  console.log('[mock-request]', config.method, config.url, config.params)
  return createChainable(config)
}
```

```vue
<template>
  <div id="preview-root">
    <component :is="mainComponent" v-if="mainComponent" />

      <div class="mock-panel-row">
        <input

<script>
export default {
  data() {
    return {
      mainComponent: null,
      loadError: null,
      mockInput: '',
    }
  },
  created() {
    // 异步加载业务组件，避免依赖链报错白屏

        this.mainComponent = mod.default
      })
      .catch((err) => {
        this.loadError = err.message || String(err)
        console.error('组件加载失败:', err)
      })
  },
  methods: {
    triggerMock() {
      if (!this.mockInput) return
      // 找到子组件实例，直接调用其方法
      const child = this.$children && this.$children[0]
      if (child && typeof child.handleSubmit === 'function') {
        // 你可以调用子组件的任何 public 方法
```

## 六、接口调用详细说明（最易踩坑的部分）

### 6.1 平台 `$request` 的调用签名

```
this.$request({ url: String, method: String, params: Object })
  → 返回链式对象（不是 Promise！）
```

链式对象的方法：

| 方法 | 签名 | 说明 |
|------|------|------|
| `.asyncThen(onSuccess, onError)` | `(resp => void, err => void) → chainable` | 成功/业务失败回调 |
| `.asyncErrorCatch(onError)` | `(err => void) → chainable` | 网络异常回调 |

### 6.2 绝对不能这样写

```js
// ❌ 错误！$request 不返回 Promise
const res = await this.$request({ url, method, params })

// ❌ 错误！没有 .then() 方法
this.$request({ url, method, params }).then(res => { ... })

// ❌ 错误！不能用 axios
import axios from 'axios'
axios.post(url, params)
```

### 6.3 正确写法（两种）

```js
// ✅ 方式一：直接链式
this.$request({ url, method, params })
  .asyncThen(
    (res) => { /* 成功 */ },
    (err) => { /* 业务失败 */ }
  )
  .asyncErrorCatch((err) => { /* 网络异常 */ });

// ✅ 方式二：包装成 Promise（需要 await 或多接口串联时）
new Promise((resolve, reject) => {
  this.$request({ url, method, params })
    .asyncThen(
      (json) => resolve(json),
      (err) => reject(err)
    )
    .asyncErrorCatch((err) => reject(err));
})
  .then((res) => { /* ... */ })
  .catch((err) => { /* ... */ })
  .finally(() => { /* ... */ });
```

### 6.4 响应结构

```js
// 成功响应
{ code: 0, data: { ... }, msg: "操作成功" }

// 失败响应
{ code: -1, msg: "预约编号不存在" }

// 权限接口特殊响应
{ code: 'ok', data: [ ... ] }
```

> 注意：业务接口用 `code === 0` 判断成功，平台标准接口用 `code === 'ok'`。

## 九、完整真实案例：TMS 扫码操作页面

以下是本项目的真实实现，展示「选择动作 → 扫码 → 调接口 → 展示结果」的完整流程。

### 场景描述

> 移动端页面，用户选择一个操作（开始卸货/开始装货/卸货完成/装货完成），
> 然后扫描二维码获取预约编号，调用后端接口推进预约状态，展示操作结果。
> 扫码支持三种环境降级：aPaaS 移动端 SDK → 企业微信 JSSDK → H5 摄像头。

```js
startScan() {
  // 优先级 1：aPaaS 移动端 SDK
  if (window.df && window.df.thirdApi && window.df.thirdApi.scanQRCodeWithPromise) {
    window.df.thirdApi.scanQRCodeWithPromise()
      .then((res) => this.onScanResult(res.result))
      .catch(() => this.showToast("扫码取消或失败"))
      .finally(() => { this.scanning = false });
    return;
  }

  // 优先级 2：企业微信 JSSDK
  const ua = navigator.userAgent.toLowerCase();
  if ((ua.indexOf("wxwork") > -1 || ua.indexOf("micromessenger") > -1) && typeof wx !== "undefined") {
    wx.scanQRCode({
      needResult: 1,
      scanType: ["qrCode", "barCode"],
      success: (res) => this.onScanResult(res.resultStr),
      fail: () => this.showToast("扫码取消或失败"),
      complete: () => { this.scanning = false },
    });
    return;
  }

  // 优先级 3：H5 摄像头（需要 HTTPS + html5-qrcode 库）
  this.h5Scan();
},
```

### H5 摄像头扫码实现要点

```js
async h5Scan() {
  this.showH5Scanner = true;
  await this.$nextTick(); // ★ 必须等 DOM 渲染出 #h5-qrcode-reader

  const { Html5Qrcode } = await import("html5-qrcode"); // 动态导入
  this.h5QrScanner = new Html5Qrcode("h5-qrcode-reader");
  await this.h5QrScanner.start(
    { facingMode: "environment" },  // 后置摄像头
    { fps: 10, qrbox: { width: 250, height: 250 } },
    (decodedText) => {
      this.onScanResult(decodedText);
      this.stopH5Scanner(); // 识别成功后立即停止
    },
    () => {} // 忽略未识别帧
  );
},

// ★ 页面销毁时必须释放摄像头
beforeDestroy() {
  if (this.h5QrScanner) {
    this.h5QrScanner.stop();
    this.h5QrScanner.clear();
    this.h5QrScanner = null;
  }
}
```

## 十、常见场景速查

| 场景 | 要点 |
|------|------|
| **表单提交** | data 里定义表单字段，button 触发 callApi，参数从 data 取 |
| **列表展示** | created 里调查询接口，asyncThen 里把 res.data 赋给列表数组 |
