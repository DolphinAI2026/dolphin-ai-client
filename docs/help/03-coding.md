# AI 编码 / 睿鲸 IDE (`/coding`)

**让 AI 帮你写自开发组件 / 页面 / 接口。** 给 aPaaS 平台增加平台不支持的扩展能力。

## 解决什么问题

aPaaS 平台的低代码搭建覆盖 80% 场景，剩下 20% 需要自开发：

- 平台不提供的表单组件（如评分组件 / 颜色选择器 / 复杂日期范围）
- 自定义页面（如项目总览看板）
- 自定义脚本 / 接口逻辑
- 平台菜单页面

AI 编码就是把这些需求用对话描述给 AI，它在 IDE 工作区里写代码，最后产出可以上传到 aPaaS 平台的组件包。

## 几种工作区类型

- **PC 组件**：表单组件、列表组件
- **PC 页面**：自定义菜单页面
- **移动端组件**：app 端表单组件
- **接口**：自定义后端接口
- **脚本**：自定义脚本

每种类型都对应一个项目模板（df-apaas-cli 拉取），项目结构 + 规范由模板决定。

## 关键能力

- **侧边栏**：左侧列出所有"已开发组件 / 页面"，点击切换工作区
- **欢迎态首页**：居中输入框 + 试试推荐 + 已开发组件卡片
- **对话 / IDE 双视图**：顶部切换；对话视图看 AI 思考过程 + 工具调用，IDE 视图直接编辑代码（code-server）
- **AI 行为**：和 Claude Code / Cursor 风格类似，能扫描文件、读取规范、写代码、重新让你预览
- **上传到平台**：开发完成后，工作区卡片上有"上传到平台"按钮，把组件包传到 aPaaS 环境

## 典型流程

1. `/coding` 进入
2. 居中输入框描述需求，比如"开发一个评分组件，支持半星和自定义颜色"
3. 选组件类型（PC 组件 / 页面 / 等）+ 模型（默认 gpt5.5）
4. 回车 → AI 在新工作区里读取 `.cursor/rules/*.mdc` 规范、`apaas.json`、入口文件
5. AI 写代码，过程在对话视图可见（思考、扫描、读、写、跑命令）
6. 切到 IDE 视图直接看 / 改代码（code-server 4.112.0 内嵌）
7. 调试完点工作区卡片上的「上传」按钮 → 选环境 → 推到平台

## 默认入口体验

进入工作区后**默认是 chat 视图**，IDE 由你主动切。避免一进来就被 IDE iframe 接管整个屏幕。

## 与 Vibe Coding 的差异

- AI 编码 = 单个组件 / 页面，模板严格、规范驱动、产物上传到 aPaaS 平台
- Vibe Coding = 完整应用，自由度高、Docker 沙箱跑、产物可独立部署
