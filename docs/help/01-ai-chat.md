# AI 对话 (`/ai-chat`)

**用对话整理需求，产出标准设计文档。** 是 AI 搭建的"前置工序"。

## 两种模式

### Chat 模式
从零和 AI 来回对话理需求。AI 会问澄清问题，你边聊边给信息，最终产出一个 markdown 设计文档。

**适合**：脑子里有个想法但还没成型，或者老板只说了一句"做个 XX 系统"。

### Cowork 模式（协作整合）
你已经有一堆零散材料（PDF / Word / Excel / 截图 / 老文档），把它们都拖进来。AI 会**并行读完所有附件**，给出综合摘要 + 批量澄清问题，再产出一份符合 Builder 规范的标准设计文档。

**适合**：客户给了一堆资料 + 你需要把它整合成可执行 PRD。

## 关键能力

- **侧边栏**：左侧列出所有会话，按 Chat / Cowork 模式分组（"+ 新会话"下拉菜单选择创建哪种）
- **附件支持**：拖入 / 粘贴 / 上传 PDF、Word、Excel、图片、Markdown
- **设计文档面板**：右侧可展开查看 AI 生成的 .md 文档，支持版本切换、原文 / 渲染切换、按规范重写
- **→ Builder**：一键把标准设计文档交给 AI 搭建模块自动搭建

## 典型流程

1. `/ai-chat` 进入
2. 左上角点 `+ 新会话` → 选 Chat 或 Cowork
3. Cowork：把所有材料拖进对话框 → 发送 → 等 AI 把摘要 + 澄清问题给你
4. 回答澄清问题 / 补充信息
5. AI 生成 `.md` 设计文档（右侧出现"设计文档"按钮 + inline 卡片）
6. 看右侧渲染版，不满意可以让 AI 改
7. 点击 inline 卡片上的「→ Builder」直接跳到 AI 搭建并把文档传过去

## 模型选择

输入框下方有模型选择器（gpt5.5 / Claude / etc），默认用首次进入会话时选的；切换后只影响后续对话。
