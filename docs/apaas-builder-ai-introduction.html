Positioning

产品定位

不是又一个低代码平台，而是低代码平台的「AI 操作层」——让不懂配置、不会写代码的业务人员，也能用自然语言交付企业应用。

面向谁。 企业实施 / 顾问 / 业务管理员 —— 面对 QMS、设备台账、审批流、现场管理、CRM 这类中后台场景，过去要在低代码平台上一个字段一个流程地点。

解决什么。 把「需求 → 应用」中间最耗人的配置与开发交给 AI：上传材料或描述需求，AI 自动产出符合平台规范的设计文档，并真实调用平台 API 把应用建出来、部署上线。

怎么不同。 AI 不是「生成一段建议让你手动照做」，而是直接操作真实平台——建模型、配表单、设流程权限、部署发布，全程有工具调用记录可查、可回溯。

核心功能

围绕「从零建应用」到「持续迭代」的完整生命周期。

AI Builder · 对话式建应用

聊需求或上传材料（PDF / Word / Excel / 截图 / 现有文档），AI 自适应判断：

  • 并行读材料、看图（vision），结构化汇总「识别到的表 / 角色 / 流程 / 字段」
  • 生成符合平台规范的 6 章设计文档，校验打分后交你审核
  • 确认后一条龙：生成应用 → 部署 → 发布上线
需求 → 应用

智能配置 · 配置助手

对已部署的应用，用自然语言改配置，改的是真配置、立即生效：

  • 「把金额字段改必填」「加个部门主管审批」「给列表加查询条件」
  • 覆盖表单 / 流程 / 权限 / 字典等场景
  • 每步工具调用 + 本次变更汇总，全程可见
对话即配置

智能开发 · 二次开发

低代码盖不住的部分，AI 写代码补齐，并配套 Web IDE：

  • 自开发组件 / 页面 / 后端接口扩展
  • AI 在应用上下文里读真实模型/菜单，生成代码并打包上传
  • 内置 code-server，工作区点开即全屏 IDE
应用上下文 codegen

资产库 & 协作

把建成的应用与可复用资产沉淀下来：

  • 应用资产库：所有应用集中管理、检索、继续编辑
  • 自开发资产库：二次开发包列表、搜索、状态、版本
  • 历史会话留存，工具调用全程记录可回溯
沉淀复用

内置 Web IDE · 人机协同二次开发

需要写代码的地方，AI 生成的代码直接落到云端工作区，你随时点开全屏 Web IDE（code-server）接着改——AI 写、人改、再打包上传回 aPaaS 应用，全程在浏览器里完成，无需本地装环境。

  • AI codegen：在应用上下文里读真实模型 / 菜单，生成组件 / 页面 / 后端接口代码
  • code-server 全屏 IDE：自开发资产库或项目里点工作区即开（:8080 浏览器内编辑、跑命令、看构建输出）
  • 构建 → 打包 zip → 上传平台 → 关联应用 → 重发布，一条龙
AI 写 · 人改 · 一键回平台

Agent 可观测 Trace 已上线

每次 agent 运行的全过程都落进统一的 agent_run / agent_step 底座。Trace 下钻已上线：点开一次对话就能看完整执行链路——每轮 LLM 思考、调了哪些工具、入参 / 结果、耗时、token，按租户隔离（会话级 + 每条回复两个入口）。聚合 dashboard 与跨链路接入在后续演进。
