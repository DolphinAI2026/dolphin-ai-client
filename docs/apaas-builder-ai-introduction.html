Positioning

不是替代低代码，而是给低代码加上 AI 操作层。

系统以自然语言和文档作为入口，以 aPaaS 平台能力作为落点，让业务人员、实施顾问和开发人员在同一条链路上协作。

对业务人员：可以从一句想法、一批附件或一份 PRD 开始，让 AI 追问、整理并产出标准设计文档。

对实施顾问：可以把文档交给 AI 搭建模块，生成应用草稿，再通过对话调整模型、表单、流程、权限和字典。

对开发人员：可以用代码工作区补齐低代码覆盖不到的组件、页面、接口和脚本，过程里能查看源码、对比变更、执行命令并沉淀开发产物。

对管理员：可以集中配置 LLM 模型、得帆云平台环境、租户成员和平台管理入口，保证应用搭建前置条件可控。

Capabilities

当前核心能力

这里按当前前端路由和页面实现整理，避免把已下线或仅存文档残留的能力写进介绍页。

AI Builder：从需求和材料开始

首页和 AI 对话共用 AIChatPage，支持新建会话、历史会话、附件输入、设计文档产出和应用就绪后的 inline 跳转。

  • 支持 PDF、Word、Excel、图片、Markdown、HTML 等附件
  • 生成应用后用卡片直接打开 Builder 或应用资产

应用搭建：在应用上下文里改真配置

从应用资产库进入编辑页，工作台展示模型、表单、流程、权限等应用配置，右侧配置助手负责用对话完成增量调整。

  • 无应用上下文直接访问 /chat 会回到应用列表
  • 支持构建、发布、继续最近对话和查看应用组成

代码工作区：补齐低代码外的扩展开发

当前 /coding 页面面向自开发组件、页面、接口和脚本。AI 会整理任务、创建工作区、读写文件、运行命令，并在同一页面查看源码和差异。

  • 对话流默认可见，文件树、源码、差异、设置和产物在工作区内协同展示
  • 支持从 Builder 回跳到对应应用继续配置

应用资产库：统一管理已生成应用

/apps 汇总展示应用状态、构建进度、组成指标和最近更新，可在列表或卡片视图中继续对话、构建、发布、导入或删除草稿。

  • 展示模型、表单、角色、字典等核心组成
  • 区分低代码应用与 AI 代码类型资产

平台环境：连接得帆云运行环境

/platform-envs 承接平台环境管理，维护得帆云连接、环境状态和默认环境，让应用构建、发布和调试有明确目标。

  • 支持按环境维护 base_url、连接状态和默认环境
  • 租户管理员可进入，普通成员按权限使用

成员与平台管理：权限入口清晰

租户成员和管理后台分别由 /tenant-users、/platform-admin 承接；平台环境和模型配置由 /platform-envs 集中管理。

  • LLM 支持 OpenAI、Anthropic、DeepSeek、自部署 vLLM 等
  • 平台环境、成员角色和平台管理员入口按权限开放

Modules

主要页面与入口

左侧导航和关键路由围绕实际工作场景组织，用户不用先理解底层平台概念，也能完成任务。

首页与 AI 对话

首页复用 AIChatPage，承接新建需求、历史会话、Chat / Cowork 模式与文档产出。

应用管理

合并展示 local、linked、remote 应用，支持打开编辑、跳平台、部署、成员管理和删除草稿。

AI 搭建编辑页

中间展示应用配置工作台，右侧配置助手负责对话式调整模型、表单、流程、权限等内容。

代码工作区

面向 aPaaS 自开发页面、组件、接口和脚本，提供对话流、文件树、源码视图、差异对比和产物说明。

平台配置与成员管理

LLM 和平台环境在 /platform-envs，成员管理在 /tenant-users，平台管理员进入 /platform-admin。

Architecture

可落地的技术与集成架构

当前项目不是静态 Demo，已经具备前端工作台、FastAPI 后端、结构化 SPEC、配置助手工具链、代码工作区和平台配置管理等关键能力。

前端工作台

Vue 3、TypeScript、Vite、Element Plus、Pinia 和 Vue Router，覆盖首页、应用资产、对话、编码、平台环境、成员管理等页面。

Vue 3VitePinia

后端服务

FastAPI、SQLAlchemy async、Pydantic v2、SSE 流式响应和 JWT 认证，承接 AI 对话、应用、SPEC、编码工作区与配置管理。

FastAPISSEJWT

AI 与工具调用

支持多模型配置，AI 搭建通过配置助手和后端工具操作应用；代码工作区通过对话流、文件读写、差异查看和命令执行辅助生成扩展代码。

LLMMCPCoding

集成与运行

支持 df-apaas-cli 自开发模板、原生代码工作区、得帆云平台环境连接、租户成员管理和平台管理后台嵌入。

Value

核心价值

让业务需求更快变成可运行系统从自然语言、附件资料和标准设计文档出发，减少手工建模、配表单、配流程的重复劳动。
让低代码平台具备持续演进能力已有应用可从资产库继续对话、构建、发布和查看核心组成，降低后续维护成本。
让自开发能力接入平台工作台代码工作区围绕 aPaaS 扩展开发，沉淀页面、组件、接口和脚本产物，开发完成后回到平台场景使用。
