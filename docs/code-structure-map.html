先按这 4 步看

1. 看后端入口

从 backend/app/main.py 看现在挂了哪些 API。没挂载的路由，多半不是当前产品主线。

2. 看前端路由

从 frontend/src/router/index.ts 看用户能打开哪些页面。页面文件如果不在路由或组件引用链里，就要怀疑是否遗留。

3. 按业务流追

AI 搭建看 ai_chat、applications、builder_spec；辅助开发看 coding。

4. 再判断能不能删

先搜引用，再看路由，再跑测试。只有“无入口 + 无引用 + 无测试依赖”的文件才适合删。

核心模块职责

主前端 frontend

用户实际使用的 AI Builder、聊天、应用、Coding 页面。

后端 routes

所有 HTTP API 门面。先看这里能最快知道功能是否仍在线。

AI Chat

首页对话、会话、上传材料、产出设计文档和 artifacts。

Applications

应用列表、导入、生成、SPEC、配置助手、发布和平台数据读取。

Coding

工作区创建、代码生成、IDE 代理、构建、预览、部署到应用。

admin-spa

平台管理后台，包含租户、环境、LLM、MCP、调用日志等管理页。
