# Dolphin Code 发布会真实应用 Demo 内容包

本文档替代上一版“纯说明型会话”。发布会录屏应展示真实的应用生产过程：用户输入“我要生成/修改/测试什么应用”，系统产出应用原型、配置变更、代码工程、测试与部署材料。

核心编排：

| Demo | 入口 | 演示主题 | 应用 |
|---|---|---|---|
| Demo 1 | Code | 从业务想法生成 AI Native 全代码应用 | 销售线索评分与跟进助手 |
| Demo 2 | Builder | 修改已有低代码应用，升级为 Agentic 应用 | 项目管理低代码应用 |
| Demo 3 | Code | 为 AI Native 应用生成 Agentic 测试与部署包 | 销售线索评分与跟进助手 |

## 总体录屏路径

1. 打开 Dolphin Code。
2. 先切到 Code，打开 `Dolphin Code 发布会 Demo`。
3. Demo 1：点击 `Demo 1：Code 生成销售线索评分助手`，展示 Code 生成应用原型、业务模型、页面设计、代码工程和 Agent 能力。
4. 切到 Builder。
5. Demo 2：打开 `项目管理低代码 Demo`，点击 `Demo 2：Builder 低代码项目风险预警二开`，展示低代码已有应用的读取、变更计划、字段/表单/列表/详情页改造、Agent 工具和通知动作。
6. 切回 Code。
7. Demo 3：点击 `Demo 3：Code 生成 Agentic 测试与部署包`，展示测试用例、Agentic 测试、权限测试、人工确认测试、多环境部署计划和发布说明。

## Demo 1：Code 生成 AI Native 全代码应用

### 任务输入

```text
我要生成一个“销售线索评分与跟进助手”全代码应用。

应用需要支持：
1. 销售查看线索优先级队列；
2. 系统根据来源、预算、互动、客户规模和商机信号自动计算线索评分；
3. 在线索详情页解释评分原因；
4. 自动生成下一步跟进建议、电话话术和邮件草稿；
5. 页面右侧有业务助手，可以查询客户、线索、商机和跟进记录；
6. 业务助手要能基于当前页面上下文解释评分、推荐动作、生成邮件，但涉及发送消息和转商机时需要人工确认；
7. 生成可交互原型、数据模型、页面结构、Agent 可调用能力说明和测试建议。

请按企业应用交付方式产出，不要只生成一个页面。
```

## Demo 2：Builder 修改已有低代码应用

### 被改造应用

应用名称：`项目管理低代码 Demo`

已有能力：

| 模块 | 已有能力 |
|---|---|
| 项目列表 | 查看项目名称、负责人、阶段、进度、预算、计划结束日期 |
| 项目详情 | 查看项目基础信息、里程碑、预算执行和问题记录 |
| 项目表单 | 新建/编辑项目基础字段 |
| 问题管理 | 登记问题、关闭问题、查看未关闭问题 |
| 通知 | 向负责人发送普通提醒 |
| 业务助手 | 查询项目基础状态 |

### 任务输入

```text
我要修改当前这个项目管理低代码应用，增加一个“项目风险预警助手”。

要求：
1. 读取现有页面、表单、数据模型和流程配置；
2. 不重做应用，只在已有应用上增量二开；
3. 根据延期天数、预算偏差、未关闭问题数自动计算风险等级；
4. 新增字段：风险等级、风险分值、风险原因、整改建议、预警时间、通知状态；
5. 在项目列表展示风险等级，支持按风险筛选和排序；
6. 在项目详情页增加风险预警卡片，展示风险原因和整改建议；
7. 业务助手可以查询项目状态、解释风险原因、生成整改建议，并在人工确认后触发通知；
8. 输出变更计划、字段变更、页面变更、规则变更、Agent 可调用能力、通知动作和测试建议。
```

### Builder 录屏要展示的真实产物

| 产物 | 展示点 |
|---|---|
| 应用卡片 | `项目管理低代码 Demo` 是 Builder 低代码应用，不在 Code 应用组里 |
| 会话 | `Demo 2：Builder 低代码项目风险预警二开` |
| 原应用结构 | 项目、里程碑、问题、通知、项目表单 |
| 变更计划 | 字段、列表页、详情页、规则、助手、通知 |
| 配置预览 | `config_preview` 中能看到新增风险字段和项目风险预警助手 |
| 产物文档 | `project-risk-warning-builder-change.md` |

### 变更结果

| 区域 | 变更 |
|---|---|
| 数据模型 | Project 增加 `delay_days`、`budget_deviation_rate`、`open_issue_count`、`risk_level`、`risk_score`、`risk_reason`、`rectification_suggestion`、`risk_alert_time`、`risk_notify_status` |
| 列表页 | 增加风险等级列、风险原因摘要、风险筛选、风险排序、批量通知 |
| 详情页 | 增加风险预警卡片、风险趋势、关键指标、整改建议、通知记录 |
| 规则 | 延期、预算偏差、未关闭问题数加权计算风险分值 |
| Agent | 查询项目、解释风险、生成整改建议、列出高风险项目、触发通知 |
| 通知 | 高风险/严重风险通知负责人，助手触发通知前需要人工确认 |

### Demo 2 金句

> Dolphin Code 让已有低代码应用，从“能用”升级为“能被 Agent 使用”。

## Demo 3：Code 生成 Agentic 测试与部署包

### 任务输入

```text
基于刚才生成的“销售线索评分与跟进助手”全代码应用，请生成测试与部署包。

测试不只覆盖页面功能，还要覆盖 Agent 如何使用这个应用：
1. 生成功能测试用例；
2. 生成 Agentic 使用测试用例；
3. 测试业务助手查询客户、线索、商机和跟进记录是否准确；
4. 测试评分解释是否可追溯到字段和跟进记录；
5. 测试生成邮件、转商机、发送通知等动作是否需要人工确认；
6. 测试不同角色下业务助手能访问的数据范围；
7. 生成开发、测试、生产三套部署计划；
8. 生成灰度、回滚、监控和发布说明。
```

| 完整测试用例 | `/tmp/agent-runtime-debug.B8xATB/workspace/delivery/test/完整场景测试用例.md` | 功能、权限、异常、助手查询 |

| 技术方案 | `/tmp/agent-runtime-debug.B8xATB/workspace/delivery/tech/技术方案.md` | 进入全代码工程后的实现边界 |

### 画面顺序

| 时间 | 画面 | 讲述重点 |
