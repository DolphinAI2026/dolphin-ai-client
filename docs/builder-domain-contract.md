# Builder Domain Contract

## 固定定义

### 数据模型
数据模型只描述数据库如何存储。

允许出现：
- 模型编码
- 模型名称
- 字段编码
- 字段名称
- 数据库字段类型
- 长度/精度

不允许出现：
- 必填
- 组件类型
- 字典编码
- 关联模型编码
- 关联显示字段编码
- 列表展示
- 查询条件
- 隐藏
- 只读
- 主表/子表页面关系

### 表单定义
表单定义只表示前台展示和交互定义。

允许出现：
- 表单编码
- 表单名称
- 绑定主表模型名称
- 主表字段组件
- 子表区域
- 子表字段组件
- 组件类型
- 必填
- 隐藏
- 只读
- 列表展示
- 查询条件
- 字典编码
- 目标表编码
- 目标字段编码
- 本表关联字段编码
- 说明

口径说明：
- 对普通字段、数据单选、数据选择，字段编码对应模型字段编码
- 对关联表单，字段编码表示组件编码，不要求在数据模型中存在
- 系统内部需要时：
  `目标表编码 -> dataSelectorConfig.otherModelCode / formAssociationConfig.targetModelCode`
  `目标字段编码 -> dataSelectorConfig.otherFieldCode / formAssociationConfig.targetFieldCode`
  `本表关联字段编码 -> formAssociationConfig.originFieldCode`

主表/子表关系属于表单定义，不属于数据模型。

### 权限定义
权限定义表示“表单 + 角色”的权限关系。

允许出现：
- 表单名称
- 角色编码
- 可暂存
- 可新增
- 可导入
- 可查看
- 可编辑
- 可删除
- 可导出
- 数据范围

不允许出现：
- 模型权限
- 角色职责说明

### 角色列表
角色列表只保留：
- 角色编码
- 角色名称

### 数据字典
数据字典只保留：
- 字典编码
- 字典名称
- 选项编码
- 选项名称

### 标准 Markdown
标准 Markdown 只做展示转换，不做兜底推断。

适用链路：
- 模板预览
- 标准设计文档预览
- 标准设计文档导出后再展示

### 业务文档
业务文档才允许走解析、修复、兜底逻辑。

## 实施原则

- 标准 Markdown 使用 `standardDocMdToStructuredDoc()`
- 业务文档解析使用 `parse_document()`
- UI 统一使用 `StructuredDocRenderer`
- 相同功能优先复用同一套展示链路，不重复维护多份语义
