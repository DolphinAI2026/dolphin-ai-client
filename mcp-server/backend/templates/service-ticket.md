# 售后工单系统

## 业务背景
客户报修后，客服创建工单，调度员派工给工程师，工程师上门维修并反馈结果，最终客户验收。需要追踪工单全生命周期。

## 审批流程

### 工单派工审批
工单创建后需要调度员确认派工：
- 客服创建工单 → 调度员审批并指派工程师 → 工程师确认接单

## 角色

| 角色 | 说明 |
|------|------|
| 客服 | 创建工单、跟踪工单状态 |
| 调度员 | 审批工单、分配工程师 |
| 工程师 | 查看派给自己的工单、填写维修结果 |
| 管理员 | 全部权限 |

## 权限设计
- 客服：可创建工单、查看所有工单、不可派工
- 调度员：可派工、查看所有工单
- 工程师：只能看派给自己的工单，可编辑维修结果
- 管理员：全部数据权限
