# 项目管理系统

## 业务背景
企业需要管理多个项目的进度、任务分配、里程碑和团队资源，确保项目按时交付。

## 功能模块

## 审批流程

### 项目立项审批
新项目需要审批：
- 项目经理提交 → 部门负责人审批 → PMO 审批 → 完成

## 角色

| 角色 | 说明 |
|------|------|
| 项目经理 | 管理自己负责的项目、分配任务 |
| 项目成员 | 查看和更新自己的任务 |
| PMO | 查看所有项目，审批立项 |
| 管理员 | 全部权限 |

## 权限设计
- 项目成员：只能看自己参与的项目和任务
- 项目经理：能看和编辑自己管理的项目的全部数据
- PMO：查看所有项目（只读 + 审批）
- 管理员：全部数据权限
