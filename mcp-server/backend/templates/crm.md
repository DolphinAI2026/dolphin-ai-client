# CRM 客户管理系统

## 业务背景
企业需要统一管理客户信息、联系人、销售跟进记录和合同，实现从线索到成交的全流程管理。

## 功能模块

### 1. 客户信息管理
管理企业客户的基本信息。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 客户名称 | 单行输入 | 是 | 公司/个人名称 |
| 客户编号 | 单据号 | 是 | 自动编号，CUS-0001 |
| 客户类型 | 下拉单选 | 是 | 大客户/中型客户/小客户 |
| 客户来源 | 下拉单选 | 否 | 官网注册/电话咨询/转介绍/展会/广告/其他 |
| 所属行业 | 下拉单选 | 否 | 制造业/互联网/金融/教育/医疗/零售/其他 |
| 客户状态 | 下拉单选 | 是 | 潜在客户/意向客户/成交客户/流失客户 |
| 联系电话 | 手机号码 | 否 | |
| 邮箱 | 电子邮箱 | 否 | |
| 地址 | 地址 | 否 | 公司地址 |
| 所属销售 | 人员选择 | 是 | 负责跟进的销售人员 |
| 备注 | 多行输入 | 否 | |

## 审批流程

### 合同审批
合同提交后需要审批：
- 发起人提交 → 销售主管审批 → 财务确认 → 完成

## 角色

| 角色 | 说明 |
|------|------|
| 销售人员 | 管理自己的客户和跟进记录，提交合同 |
| 销售主管 | 查看团队客户，审批合同 |
| 管理员 | 全部数据权限 |

## 权限设计
- 销售人员：只能看自己的客户、跟进记录、合同
- 销售主管：能看本部门的数据
- 管理员：全部数据
