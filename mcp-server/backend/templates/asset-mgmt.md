# 企业资产管理系统

## 一、系统概述

本系统用于管理企业固定资产的全生命周期，包括资产采购入库、领用分配、日常维修、定期盘点、调拨转移及报废处置等核心业务流程。

## 二、角色设计

| 角色 | 说明 |
|------|------|
| 资产管理员 | 管理所有资产信息，处理入库、调拨、报废等操作 |
| 部门负责人 | 审批本部门的资产领用、调拨和报废申请 |
| 普通员工 | 提交资产领用、维修、报废申请，查看个人资产 |
| 财务人员 | 查看资产台账、折旧数据，审批报废的财务核销 |
| 仓库管理员 | 管理资产入库出库、库存盘点 |

## 三、数据字典

| 字典名称 | 选项 |
|---------|------|
| 资产分类 | 电子设备、办公家具、交通工具、生产设备、网络设备、软件资产 |
| 资产状态 | 闲置、在用、维修中、已报废、已调拨 |
| 采购方式 | 集中采购、部门自采、捐赠、租赁转购 |
| 领用类型 | 个人领用、部门共用、项目专用 |
| 维修类型 | 保修维修、付费维修、自行维修 |
| 维修紧急程度 | 紧急、一般、低优先级 |
| 报废原因 | 自然损耗、技术淘汰、意外损坏、丢失 |
| 盘点结果 | 正常、盘盈、盘亏、损坏 |
| 折旧方式 | 直线法、双倍余额递减法、年数总和法 |

## 五、审批流程

### 5.1 资产领用审批
- 申请人提交 → 部门负责人审批 → 资产管理员确认出库 → 完成

### 5.2 资产维修审批
- 报修人提交 → 部门负责人审批 → 资产管理员安排维修 → 完成

### 5.3 资产调拨审批
- 申请人提交 → 调出部门负责人审批 → 调入部门负责人确认 → 资产管理员执行调拨 → 完成

### 5.4 资产报废审批
- 申请人提交 → 部门负责人审批 → 资产管理员审核 → 财务人员核销 → 完成

## 六、权限设计

- 资产管理员：所有表单全部操作权限，数据范围为全部
- 部门负责人：查看本部门及下级数据，审批领用/维修/调拨/报废
- 普通员工：查看和新增本人数据，可提交领用、维修、报废申请
- 财务人员：查看全部资产台账和折旧记录，审批报废核销
- 仓库管理员：管理入库单、盘点单，查看资产台账全部数据
