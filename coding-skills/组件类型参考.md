# aPaaS 平台组件类型完整参考

本文档是 AI Coding 模块生成表单配置时的核心字典，定义了每种业务字段应该使用的组件类型及其配置要求。

## 需要特殊配置的组件

### 数据单选 (FORM_DATA_SELECTOR_SINGLE)

引用其他数据模型的单条记录，需要 `dataSelectorConfig`：

```json
{
  "componentType": "FORM_DATA_SELECTOR_SINGLE",
  "modelField": {
    "name": "customer",
    "fieldName": "客户",
    "fieldType": "STRING",
    "businessObjectFieldType": "BOF_SINGLE_DATA_SELECTOR"
  },
  "dataSelectorConfig": {
    "otherModelCode": "customer_model_code",
    "otherFieldCode": "customer_name_field_code",
    "filterConditions": []
  }
}
```

### 数据多选 (FORM_DATA_SELECTOR)

引用其他数据模型的多条记录：

```json
{
  "componentType": "FORM_DATA_SELECTOR",
  "modelField": {
    "name": "engineers",
    "fieldName": "工程师列表",
    "fieldType": "STRING",
    "businessObjectFieldType": "BOF_MULTI_DATA_SELECTOR"
  },
  "dataSelectorConfig": {
    "otherModelCode": "engineer_model_code",
    "otherFieldCode": "engineer_name_field_code",
    "filterConditions": []
  }
}
```

### 下拉单选 (FORM_SELECT_INPUT_SINGLE)

关联数据字典的下拉选择，需要 `dictionarySelectConfig`：

```json
{
  "componentType": "FORM_SELECT_INPUT_SINGLE",
  "modelField": {
    "name": "status",
    "fieldName": "状态",
    "fieldType": "STRING",
    "businessObjectFieldType": "BOF_CHECKBOX_INPUT_SINGLE"
  },
  "dictionarySelectConfig": {
    "dictionaryCode": "order_status_dict_code",
    "options": [
      { "code": "DRAFT", "value": "草稿" },
      { "code": "SUBMITTED", "value": "已提交" },
      { "code": "APPROVED", "value": "已审批" }
    ]
  }
}
```

### 下拉多选 / 多选框 (FORM_SELECT_INPUT / FORM_CHECKBOX_INPUT)

与下拉单选类似，同样需要 `dictionarySelectConfig`：

```json
{
  "componentType": "FORM_SELECT_INPUT",
  "dictionarySelectConfig": {
    "dictionaryCode": "tag_dict_code",
    "options": [
      { "code": "TAG_A", "value": "标签A" },
      { "code": "TAG_B", "value": "标签B" }
    ]
  }
}
```

### 子表 (FORM_WIDGET_SON_TABLE)

子表需要**独立的数据模型**，在表单配置中通过 `tableColumn` 定义子表列：

```json
{
  "componentType": "FORM_WIDGET_SON_TABLE",
  "modelField": {
    "name": "order_items",
    "fieldName": "订单明细",
    "businessObjectFieldType": "BOF_SON_TABLE"
  },
  "tableColumn": [
    {
      "componentType": "FORM_TEXT_INPUT",
      "modelField": { "name": "item_name", "fieldName": "商品名称", "fieldType": "STRING" }
    },
    {
      "componentType": "FORM_NUMBER_INPUT",
      "modelField": { "name": "quantity", "fieldName": "数量", "fieldType": "NUM" }
    },
    {
      "componentType": "FORM_MONEY_INPUT",
      "modelField": { "name": "unit_price", "fieldName": "单价", "fieldType": "NUM" }
    }
  ]
}
```

**重要**：创建表单时 `allModelCodes` 必须同时包含主表和子表的数据模型编码。

### 关联表单 (FORM_ASSOCIATION)

关联到其他表单的数据，需要 `formAssociationConfig`：

```json
{
  "componentType": "FORM_ASSOCIATION",
  "modelField": {
    "name": "related_orders",
    "fieldName": "关联工单",
    "businessObjectFieldType": "BOF_ASSOCIATION"
  },
  "formAssociationConfig": {
    "associationFormId": "target_form_id",
    "associationModelCode": "target_model_code",
    "associationFieldCode": "target_field_code"
  }
}
```

### 他表字段 (FORM_OTHER_TABLE_FIELD)

显示其他表中引用记录的某个字段值（跟随数据单选自动填充）：

```json
{
  "componentType": "FORM_OTHER_TABLE_FIELD",
  "modelField": {
    "name": "customer_phone",
    "fieldName": "客户电话",
    "fieldType": "STRING",
    "businessObjectFieldType": "BOF_OTHER_TABLE_FIELD"
  },
  "otherTableFieldConfig": {
    "sourceFieldCode": "customer",
    "otherModelCode": "customer_model_code",
    "otherFieldCode": "phone_field_code"
  }
}
```

## 字段类型 (fieldType) 速查

| fieldType | 说明 | 对应数据库类型 |
|-----------|------|--------------|
| `STRING` | 字符串 | VARCHAR |
| `NUM` | 数字 | DECIMAL/BIGINT |
| `DATE` | 日期时间 | DATETIME |
| `BIG_TEXT` | 大文本 | TEXT/LONGTEXT |

## 编码规范

- 所有编码自动追加 4 位随机后缀（如 `_a3x7`）避免冲突
- 字典编码格式：`dict_{name}_xxxx`
- 模型编码格式：`model_{name}_xxxx`
- 字段编码格式：`field_{name}_xxxx`
- 角色编码格式：`role_{name}_xxxx`
