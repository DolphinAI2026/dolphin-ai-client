## 四、数据模型

> 字段类型：单行输入 / 多行输入 / 数字 / 金额 / 日期时间 / 开关 / 单据号 / 附件上传 /
> 人员选择 / 部门选择 / 地区地址 / 超链接 /
> 下拉单选（需字典编码）/ 下拉多选（需字典编码）/
> 数据单选（需关联模型编码）/ 数据选择（需关联模型编码）/ 关联表单（需关联模型编码）/
> 子表（关联模型编码填子表模型编码）

### 模型名称（model_code）【主表】

| 字段编码 | 字段名称 | 字段类型 | 字典编码 | 关联模型编码 | 关联显示字段编码 |

## 五、表单配置

> 只需配置需要自定义显示的表单，未配置的表单由系统自动生成默认配置。

### 模型名称（model_code）

| 字段编码 | 字段名称 | 是否隐藏 | 是否只读 | 是否必填 | 是否列表展示 | 是否查询条件 |

| name | 名称 | 否 | 否 | 是 | 是 | 是 |
| status | 状态 | 否 | 否 | 是 | 是 | 是 |
| owner | 负责人 | 否 | 否 | 是 | 是 | 是 |
| dept | 所属部门 | 否 | 否 | 是 | 是 | 否 |
| date | 日期 | 否 | 否 | 否 | 是 | 否 |
| amount | 金额 | 否 | 否 | 否 | 否 | 否 |
| ref_id | 关联记录 | 否 | 否 | 否 | 是 | 是 |
